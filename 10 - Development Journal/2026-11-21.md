## Owner feedback: count-in button, a simpler opening screen, then lag and skipping on big projects
- Count-In button beside the metronome (`IconButton.isActive`).
- The opening screen is now a short guide to a blank project:
  - New Audio Track and New Instrument Track as cards;
  - six essential keys;
  - links to open, import, or bring in a project.
  - The templates and recent list are removed.
- Measurement: `Dalnok <project> --perf <s>` (PerfProbe.swift).
  - It waits for plug-ins, silences the master, and plays on the real device.
  - It reports engine overloads, isolated misses and budget skips, and per-pass main-thread busy time.
- Test projects, generated: 128 tracks × 3 min of audio, plus copies with 4 Apple effects on 32 or all 128 tracks (AUReverb2, AUDelay, AUNBandEQ, AUDynamicsProcessor).
- The owner's running 0.2.1 showed about 50 % CPU. A 3 s read-only `sample` showed its main thread 78 % busy, mostly in CA commits redrawing device-panel faceplates and meters.
- Causes found and fixed:
  1. `refreshBypass` set `dimmed` on every faceplate control four times a second. `dimmed`, `value`, `tint`, `legends` and `text` all redrew unconditionally, so all controls were redrawn each time. They now redraw only on change, and redundant light fades are skipped.
  2. Every `dalnok_plugin_parameter` call on an isolated plug-in was a socket round trip waiting on the host's main thread, and display format closures called it while drawing. Now one `opParameters` round trip fetches them all, with an 80 ms cache.
     - The test caught a stale-on-arrival timestamp: the cache time was taken before the round trip. It is now stamped from the reply.
  3. Header meters and gain rings for all 128 tracks updated every frame. Now only visible rows and mixer strips update.
  4. Recovery snapshots fetched every isolated state (260 ms at 512 units). Unchanged states are now reused, and project saves still ask.
  5. The isolated budget was a fixed 40 % of the block. It is now adaptive: the engine measures its own work, excluding host waits, and the budget is 90 % less 1.5× that, kept between 40 and 85 %.
- Numbers (release, 20 s): fx32 UI stalls over 50 ms 52 → 0, p99 50 → 16 ms. fx128 budget skips 150 → 0 and overloads 0, worst block 5.9 ms; in-process the same project's worst block is 7.5 ms.
- The self-test failed twice with the screen locked: the display link doesn't fire, so glides never landed. `MotionDriver` now applies the end state on a timer as well. The self-test passes locked.
- Not done:
  - Measuring the owner's own projects, which needs their go-ahead.
  - Spreading the first snapshot's state fetch across idle ticks.

## Owner feedback: no shortcuts on the new project screen; choose shortcuts at first launch; research start screens
- Research covered Logic's Project Chooser, Studio One's Start page, Pro Tools' Dashboard, Cubase's Hub, Bitwig's Dashboard and Ableton, plus empty-state guidance. The table and decisions are in `06 - Design/New Project Screen 2026-11-21.md`.
  - They share three things: project basics (tempo, time signature, sample rate) and the audio device before the first track; recent projects one click away; and one clear way to start.
- The new project screen is built on that, with two columns.
  - Left: project basics, with tempo and time signature through the control bar's own path. Below them, the output and input with the sample rate, Audio Settings…, then Audio Track and Instrument Track.
  - Right: recent projects (hidden in automated runs), then Open, Import Audio, and Bring in a project.
  - The key hints are gone from the cards as well.
- First launch uses `ShortcutChooserController` (FirstLaunch.swift) instead of the Migration Assistant. It offers six apps plus Dalnok's own; a click applies the preset and closes the window. The Migration Assistant stays in Help.
- The self-test caught that leaving the tempo field unchanged created a "Tempo" undo step (the import undo check failed). The field now commits only real changes.
- Self-test: 621 checks (Graphite, 48 kHz) and 606 (Warm Analog, 44.1 kHz), both PASS.
