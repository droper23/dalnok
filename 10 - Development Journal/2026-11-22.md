# 2026-11-22

## Backlog, Dalnok Compressor, two new themes (Prism and Atelier)
- Backlog: removed finished items (track groups, AU sidechain fixture, out-of-process hosting).
- **Dalnok Compressor** (built-in, ADR-0011 pattern): threshold, ratio, quadratic soft knee, attack/release smoothed
  in dB, peak/RMS detection, key high-pass and key listen, mix, auto gain, and a read-only Gain Reduction meter
  (read-only parameters are never automated or saved). Eight engine tests compare it with an independent Swift
  reference (2e-6), the static curve (0.001 dB), the meter (0.01 dB), attack/release time constants, sidechain
  keying, filter/listen and save/reopen. Bug found by `liveDisconnectStopsReadingTheOldKey`: after a sidechain was
  disconnected the insert kept the old key pointer; `render.cpp` now clears every insert's sidechain each block
  before feeding them. Not yet measured against Logic's compressor (needs the owner's template).
- **Themes.** The theme system became palette per version (light/dark) + presentation families (`Look`) +
  typography roles + per-material kits. Graphite and Warm Analog keep their look and are derived from the families.
  - Prism (dark and light): a static light field with frosted, lensed glass panes drawn by Dalnok (no system
    materials, so it ports and shows in captures); floating capsules; prism playhead; light-pipe meters.
  - Atelier (light and dark): ink on paper, phrase rules, crop-mark selection, section headings, engraved piano
    roll, schematic devices, and the Composition Overview (⌥⌘O, built from markers, clips and volume automation).
  - Fonts bundled under the SIL OFL (Sora, Geist Mono, IBM Plex Sans Condensed/Mono, Source Serif 4) for the
    cross-platform future, registered at launch.
  - View ▸ Theme lists the four themes plus Match System / Light / Dark; Settings has a "Light or dark" row.
- Bugs found on the way: views draw outside their bounds on macOS 14+ (Prism panes vanished in captures until the
  field was clipped); captures need `layoutSubtreeIfNeeded` because off-screen windows don't lay out; a narrow
  window let the transport overlap the tools (all themes; fixed with a 20 pt minimum gap); the first-launch window
  was off-centre in Atelier.
- Evidence: `swift test --disable-sandbox` 279 tests pass; gen-api up to date. Self-test PASS for Graphite (908),
  Prism Dark (908), Atelier Dark (908), Atelier Light 44.1 kHz (889), Prism Light 44.1 kHz (889), Warm Analog
