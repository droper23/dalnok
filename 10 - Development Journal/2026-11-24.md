# 2026-11-24

**Ten-tester bug hunt** on `feat/clip-editor-quantize`. The owner asked for up to ten low-cost agents with different
perspectives and skill levels, one of them on real keyboard and mouse input, the rest simulated. Each worked in its own
worktree on the prebuilt binaries, under a renamed copy of the app so preferences never touched "Dalnok". The first
attempt ran out of disk (a debug build is about 3 GB per worktree), so the agents ran in waves and deleted their builds.
The second hit the rate limit and was resumed.

Perspectives: Logic power user (real input via `drive.swift`), GarageBand beginner, mastering engineer (levels),
theme auditor, Ableton producer, Logic MIDI composer, copy editor, adversarial QA (3,304 fuzzed CLI commands plus
hostile files for every importer), band/mixer engineer, keyboard/VoiceOver/performance.

**Fixed** (12 commits, each with a test, self-test step or snapshot):
- Engine: transposing kept a quantized clip's warp; whole-arrangement export rings out (`dalnok_render_to_wav_tail`),
  trimmed to the last audible block so silent endings keep their exact length (the self-test's export check caught
  the first version padding 0.5 s); notes can no longer be quantized, dragged or nudged out of their clip window;
  quantize strength 0 is a no-op; meter clip lamp with a DC offset; non-finite float samples decoded as 0; REAPER
  nesting limit (stack overflow); `clip.move` int64 overflow; `takes.makeFolder` validation (saved unloadable projects).
- App: I chip on mixer strips, themed toasts, Mixer/Devices on the start page explain themselves, empty-arrangement
  hint, VoiceOver names on welcome buttons, `[`/`]` note selection and a VoiceOver value for the piano roll, Prism Light
  `Theme.accentText`, copy edits (plug-in, US spelling, minus sign, snap hint).

**Measured fine:** fader/master/clip gain exact to 0.001 dB, constant-power mono pan (+3.01 dB hard), balance stereo pan,
click-free fades, sample-exact placement, no denormal tails. Perf (release, 64 tracks, `--perf 20`): 0 overloads, worst
render 0.34 ms, main-thread pass p50 3.5 ms / p99 7 ms.

**Verified:** `swift test` 307 pass; self-test matrix 12/12 PASS.

**Not fixed / next** (see CURRENT_STATE): tempo change leaves markers, automation and cycle at fixed frames; same
start+pitch notes collide (`NoteKey`); velocity lane draws chord stems on top of each other; no dither on 16-bit
export; no LUFS/true-peak; `textFaint` under 4.5:1 on controls in several looks; out-of-range values silently clamped
by commands; `session.describe` prints a warning on stdout (breaks JSON); default key map lacks a create-track key
(Logic users press ⌘T); the docked piano roll's theme fix not yet seen in a snapshot.

**Afternoon: the open bugs, then parity features.** The owner asked to fix everything and work toward full parity.
- All eight open bugs fixed with tests. One finding was a misreading: ⌘T in Logic splits at the playhead, and New Tracks
  is ⌥⌘N, which Dalnok's default already uses; the Logic preset now maps ⌘T to split.
- The export ring-out from the morning padded every export with 0.5 s of silence (the self-test's exact-length check
  caught it); the tail now ends at the last audible block.
- Features, each with an engine test with tolerances and a self-test step where there is UI: stock Delay, Reverb and
  Gate; Bounce Track in Place; LUFS and true peak (EBU 3341-style signals, mutation-checked); AIFF/FLAC/ALAC/AAC export;
  Export Stems (stems sum to the mix within 1e-5); MIDI Functions.
- Self-test lessons: the palette check for "bounce" expected Export Mix first (now both appear); an exported-stems
  folder named `stems` collided with the stems-import fixture.
- `site/parity.json` had an entry whose id held a paragraph of evidence (from eb493c6); repaired.
- Clip loop: compiled into one ordinary rendered clip per pass, so the audio thread is unchanged. Found on the way:
  the content cache key didn't include loop fields (now it does, with the controller list).
- MIDI controllers: one more event kind through every host. VST3 needs the plug-in's IMidiMapping (block-rate
  parameter changes); the test VST3 synth now maps CC 1 to its level so the hosting suites prove delivery in and out
  of process. Live keyboard controllers reach plug-in instruments (sustain pedal). Recording them is still to do.
- A committed test failed once this session (the every-version format test needed a v16 fixture); fixed in the next
  commit. Lesson: chain the commit after the test result, not after the command.
