## Research
Steinberg relicensed the VST3 SDK to MIT in Oct 2025, which makes a permissive, independent engine
practical. JUCE is AGPLv3 or commercial. Tracktion Engine is GPLv3 or commercial and needs a JUCE
license too. Audacity 4.0 (Sep 2026) is a Qt6 rewrite without MIDI or a mixer. See [[Foundation Evaluation]].

## Built
Engine (C API, Core Audio, snapshots, transport, gain/pan/mute, media, peaks, offline render, WAV
export), macOS app, CLI, tests, and CI.

## Problems hit
- The macOS SDK declares `AURenderCallback` with the real-time effect, so our callback chain had to be
  `nonblocking` end to end. Kept, since it's a free safety net. A negative test proves violations fail the build.
- Apple clang 21 has no `-fsanitize=realtime`. RealtimeSanitizer is planned via Homebrew LLVM.
- One round-trip test failure was a test bug: the signal reached −1.006 full scale, which integer formats correctly clip.

## Tests
`swift test`: 10/10 (21 cases). Live CLI smoke tests: PASS. UI snapshot reviewed.

## Later the same day: Phase 1 M2

### Built
Engine-owned model and media pool, snapshot undo with groups, the command catalog (JSON), and project
save/load (JSON v1, atomic, relative paths, offline media). UI rebuilt as a read-only view with clip
move, trim, split, and delete, undo menus, file commands, and export. App self-test mode.

### Problems hit
- **The self-test found a real bug.** Menu items had no target, so they relied on the responder chain,
  which only reaches the window controller when the window is key. Undo, Delete, Split, and New were
  disabled whenever the window wasn't key. Fix: explicit targets.
- Test-data assumptions: fixed-pixel drags broke on a 1.5 s clip. Drags are now fractions of clip width.
- Apple's WAV writer adds a ~4 KB `FLLR` padding chunk, so export is now verified by decoding, not by file size.

### Tests
26 engine tests pass. Self-test passes 28/28 on two media sets. Live smoke test passes. RT effect script passes locally.
