## Decisions (owner Q&A)
Logic user. Unified clip/timeline model. Portable engine with native UI. Owner acts as product owner.
VST3 first. Private repo. Placeholder name. GPLv3+. Independent engine. Milestone check-ins.

## Research
Steinberg relicensed the VST3 SDK to MIT in Oct 2025, which makes a permissive, independent engine
practical. JUCE is AGPLv3 or commercial. Tracktion Engine is GPLv3 or commercial and needs a JUCE
license too. Audacity 4.0 (Sep 2026) is a Qt6 rewrite without MIDI or a mixer. See [[Foundation Evaluation]].

## Built
Engine (C API, Core Audio, snapshots, transport, gain/pan/mute, media, peaks, offline render, WAV
export), macOS app, CLI, tests, and CI.

## Problems hit
- The macOS SDK declares `AURenderCallback` with the real-time effect, so our callback chain had to be
  `nonblocking` end to end. Kept, since it's a free safety net. A negative test proves violations fail the build.
- Apple clang 21 has no `-fsanitize=realtime`. RealtimeSanitizer is planned via Homebrew LLVM.
- One round-trip test failure was a test bug: the signal reached −1.006 full scale, which integer formats correctly clip.

## Tests
`swift test`: 10/10 (21 cases). Live CLI smoke tests: PASS. UI snapshot reviewed.

## Later the same day: Phase 1 M2

### Built
Engine-owned model and media pool, snapshot undo with groups, the command catalog (JSON), and project
save/load (JSON v1, atomic, relative paths, offline media). UI rebuilt as a read-only view with clip
move, trim, split, and delete, undo menus, file commands, and export. App self-test mode.

### Problems hit
- **The self-test found a real bug.** Menu items had no target, so they relied on the responder chain,
  which only reaches the window controller when the window is key. Undo, Delete, Split, and New were
  disabled whenever the window wasn't key. Fix: explicit targets.
- Test-data assumptions: fixed-pixel drags broke on a 1.5 s clip. Drags are now fractions of clip width.
- Apple's WAV writer adds a ~4 KB `FLLR` padding chunk, so export is now verified by decoding, not by file size.

### Tests
26 engine tests pass. Self-test passes 28/28 on two media sets. Live smoke test passes. RT effect script passes locally.

## Phase 1 M4 (Phase 1 complete)
Fades and crossfades (envelope "covers" what is beneath it), solo, track management, relink, and
copy-on-save. Self-test: 69 checks. Engine tests: 45. Benchmark: linear scaling, 256 tracks at 3% load.
Bug found by the self-test: Space typed in the rename field toggled playback (AppKit consumes matching
key equivalents even when disabled). Fixed with a `MainMenu` subclass. See [[Phase 1 Exit Review]].

### CI crash after M4 (fixed)
CI segfaulted (signal 11) in the test run. Locally everything passed. AddressSanitizer pinpointed a
**test-only** use-after-free: the relink test released a media handle and then passed it to the API
again. Fixed, and a `sanitizers` CI job (ASan + TSan) now runs on every push, so this class of bug
fails deterministically. The engine itself was clean under both sanitizers, and so was the app self-test under ASan.

## Time stretch (M6). Owner: "Do whatever you think is best"
Chose time-stretch before recording: it fixes the just-built imports, it's testable without hardware,
and recording needs the Scarlett connected. [[ADR-0007 Time stretch]].
- Tests measure pitch and level on rendered output. A mutation (forcing varispeed) makes them fail.
- **Real imports:** a set with 334 stretched clips imports and pre-renders in 1.7 s (release build).
- **Self-test:** an ⌥-drag stretch renders in the background in about 180 ms. TSan is clean with the worker thread.
- **Label fix:** "×1.10" on a slowed clip read as faster, so it now says "91% speed".

## Track gain and Logic comparison
Replaced the track fader with a labeled gain knob beside labeled pan. Its halo follows the post-fader peak, switching to gain position during interaction. The GUI self-test covers the live level, drag, reset, undo, and Space typing/playback. A disposable Logic 12.2 project containing a system audio sample and its FCPXML export each imported as one track and one clip with no offline media. Logic rendered the XML audio to 65,536 frames; the native project imports at about 1.5 s versus 1.4 s for the export, so this is not proof of exact placement.

## Recording foundations and import hardening
ADR-0008 defines a same-device duplex recording path, bounded capture, writer failure semantics, recoverable temporary files, and explicit verification gates. No capture code exists yet. Logic importer rejects malformed chunk and name lengths; a controlled audio-only Logic project showed that type 0x20 cannot yet be counted as MIDI regions. Three targeted Logic tests pass. GUI self-test verifies Space start and pause, including with gain-knob focus.

## Unified Open and Scarlett check
Open accepts native and foreign projects and stem folders; foreign selection asks Import or Cancel, and the separate import menu is removed. The picker filters by extension rather than depending on Logic UTI registration. Self-test covers Logic package eligibility and cancel/confirm import. Scarlett Solo 4th Gen is connected at 48 kHz (4 input and 2 output channels); an external 2.66 s four-channel capture had a -62.9 dBFS peak on the first two channels, insufficient to confirm usable microphone signal. Dalnok capture is not yet built.
