# Contributing

1. Read `AGENTS.md`. It applies to humans too.
2. Run `scripts/check.sh` before opening a PR. CI runs build and tests on macOS.
3. Engine changes need tests, and audio changes need offline-render tests with explicit tolerances.
4. Architectural changes need an ADR in `09 - Decisions/`.
5. By contributing you agree your work is licensed under GPL-3.0-or-later.
