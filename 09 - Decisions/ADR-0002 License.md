# ADR-0002: GPL-3.0-or-later
**Decision.** The project is licensed GPL-3.0-or-later (owner choice), with a permissive-only dependency policy.
**Consequences.** Forks stay open. Optional GPL components remain possible. Relicensing would need every
contributor's consent, so we decide on a CLA policy before accepting outside contributions.
**Rejected:** MPL-2.0 and Apache-2.0, which would allow closed derivatives.
