# UI/UX review: every main interaction in both themes

## How it was reviewed
- Generated projects only (`scripts/make-test-project.sh` demo, band, midi, states). Never the owner's material.
- `Dalnok <project> --uiwalk <dir>` drove the app with real `NSEvent`s through each window: clip select,
  marquee, fade drag, header chips, gain-knob drag, rename + Escape, ⌘K palette with typing, tempo/meter changes,
  Space playback, zoom, double-click into the piano roll, note marquee, velocity drag, device panel, AU plug-in
  window, Settings, Plug-ins, Concept Guide, Welcome and the empty state. Every visible window was captured at
  each step (mid-drag too), in Graphite and Warm Analog.
- OS-level input (CGEvent) was ready (`scripts/dev/drive.swift`, Accessibility granted) but the Mac's screen was
  locked during the session, so no clicks were posted at the OS level. Events were delivered in-process to the
  hit-tested view (the same routing AppKit uses for a key window). Screen Recording isn't granted, so the app
  draws its own windows (`DALNOK_WINDOW_DUMP`).

## Bugs found and fixed
| Found | Fix |
|---|---|
| Zoomed or scrolled, clip bodies drew over the track headers (macOS 14+ `clipsToBounds` defaults to false) | Timeline and piano roll clip to their bounds |
| Escape didn't cancel a track rename; the next keys (⌘K, Space) typed into the name | Escape restores the old name and ends editing (self-test) |
| Warm Analog: the name field turned dark-on-dark while editing, and the masking tape vanished after a rename | Edit on the tape with dark ink; the tape stays |
| Apple AU editors (AUDelay) clipped: they resize after joining the window without telling the host | Resizable editors fill the window; fixed-size ones are re-measured once. (An engine-side frame observer crashed AppKit's tracking areas and was reverted.) |
| Quitting with unsaved changes, then Cancel (or a cancelled Save As), left the app stuck waiting to quit | `confirmDiscard` reports cancellation; quit gets an answer |
| Save As menu item targeted a selector with closure parameters AppKit can't fill | Plain `saveDocumentAs(_:)` action plus a Swift `saveAs(then:otherwise:)` |
| Palette: "tempo" ranked "System Default (MacBook Pro Speakers)" among the top hits | Whole-word and substring matches score higher; scattered matches drop out (self-test) |
| Gain value bubble covered the track name while dragging | Bubble sits below the control, over its caption |
| Plug-ins window footer ran edge to edge | Constrained to the content margins |

## Workflow and clarity improvements
- **Playhead clicks snap to the grid** (⌃ for exact), so the LCD reads 25.3.1.000, not 25.3.4.231 (self-test).
- **Keyboard zoom keeps the playhead in place** when it's on screen.
- **Device panel:** an "+ Add Plug-in" tile after the chain (before, the only way to add a second plug-in was the
  menu); knobs centred in the unit; long parameter names wrap to two lines with the full name as a tooltip; the
  empty message no longer repeats the button.
- **Empty state:** New Audio Track and New Instrument Track buttons, so someone with a keyboard can start playing
  without hunting the Track menu (self-test).
- **Piano roll subtitle:** snap value (and ⌃ to bypass), selection count, pitch and velocity range.
- **MIDI clips are named after their track** (older "MIDI" names display as the track name).
- **Welcome:** the first step is centred in the window and "Something else, or start fresh" is a quiet link,
  not a mismatched grey button.
- **Settings:** a theme change offers **Relaunch Now** (reopens with the saved project after the usual save prompt).
- **Ruler:** bar numbers sit above the playhead head, so bar 1 is readable at the start.

## Aesthetics, by perspective
- **Recording musician (Logic user):** the arrangement reads well in both themes; track colors carry lane identity
  and selection is unmistakable (white outline). Warm Analog's LEDs and tape labels are characterful without
  hurting legibility. Remaining friction: no visible input level on armed tracks before recording.
- **Producer at a laptop:** information density is good at 1920×1050. The device panel (196 pt) is mostly empty
  for a track with no plug-ins; consider letting it collapse to a header when empty.
- **Accessibility:** quiet piano-roll notes were near-invisible in Warm Analog; notes now have a bright start cap
  and top edge. Color still carries mute state and velocity; VoiceOver, keyboard-only use and contrast of blended
  clip colors remain untested.
- **Visual designer:** Graphite is crisp but cool and flat; its master meter is nearly invisible when idle.
  Warm Analog is the stronger identity. Both themes share layout and semantics, which is right.
- **Engineer:** the review tooling (`--uiwalk`, window dump, drive tool) makes this repeatable; extend the walk
  when adding UI.
